# Контекст за Claude

## Проектът

Собствен CNC контролер. Orange Pi One (Allwinner H3, 512 MB RAM) е горното ниво, STM32H723 изпълнява движението. Подробностите са в `docs/`.

## Правила за работа с потребителя

- Пиши на български.
- Без анкети и изскачащи въпросници. Ако има няколко въпроса, задавай ги **един по един** в чата и изчаквай отговор, преди да минеш на следващия.
- Готовите програми (LinuxCNC, grblHAL, Mach3, arisc, Klipper) се ползват само като справка. Всичко се пише от нулата.
- При избор между варианти давай препоръка, а не изброяване.

## Ключови решения (не ги преразглеждай без причина)

- **ОС:** Armbian Minimal (Debian), собствено ядро с `PREEMPT_RT`, без X сървър. На Raspberry Pi: Raspberry Pi OS Lite.
- **Linux платката е сменяема** (Orange Pi или Raspberry Pi; списък в `docs/platki.md`). Само стандартни интерфейси (DRM/KMS, libinput, spidev, libgpiod); всичко зависимо от платката е в `board/*.conf`; компилира се за armhf и arm64. За серийните машини целта е Compute Module 4/5 върху собствена платка.
- **Платка за STM32:** WAVGAT STM32H723ZGT6 core board (AliExpress), не Nucleo. Няма вграден ST-LINK (нужен е външен, напр. ST-LINK V3MINIE); кварцът, пинът на светодиода и захранването на ядрото (LDO) се проверяват по платката.
- **Среда за STM32:** VS Code на Windows 10 + разширение STM32Cube for VS Code, STM32CubeCLT, STM32CubeMX (проект с CMake).
- **Разделение:** Linux чете G-code, интерпретира и планира (look-ahead, S-крива). STM32 получава готови сегменти по SPI и генерира стъпки, затваря контура по енкодерите, засича пробника хардуерно и следи безопасността (watchdog, плавно спиране).
- **MCU:** STM32H723ZG, не ESP32 (детерминизъм, таймери с encoder mode, input capture, много GPIO).
- **Енкодери:** 6 оси + шпиндел = 7 канала на хардуерни таймери. Стъпките се генерират с един таймер + DMA към GPIO, за да останат таймерите за енкодерите.
- **Корекцията по енкодер е в STM32**, не в Linux. Режими за всяка ос: отворен, затворен (стъпков + енкодер), двоен (серво + линийка).
- **UI:** LVGL през DRM, HDMI екран + USB тъч панел. Портретна ориентация по подразбиране (800×1280), поддържа и хоризонтална.
- **Шрифтове:** Barlow Condensed (надписи), Barlow (текст), JetBrains Mono (числа). Всички с OFL лиценз, конвертират се с `lv_font_conv`.

## Поетапност

- **Макросите и логиката** (M100–M199, PLC правила, Lua) идват **след** стабилната основа, като обновяване (`docs/makrosi-logika.md`). Не се започват преди това, но в основата се оставя място за тях (таблица на M-кодове, общ слой за входове и изходи, резервирано поле в SPI, нива на достъп).

## Макетът

`ui/maket.html` е еталонът за интерфейса. При нови изисквания първо се променя макетът, след това кодът. Всеки елемент има съответствие в LVGL (описано под макета).
